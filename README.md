# Aeria

Local Codex workspace for the original Aeria civic evidence application.

An editable local reconstruction is now available. With Node 24.18+, run `npm run demo`, then open `http://127.0.0.1:4310`. Run `npm test` for governance and auth verification. No dependency installation is needed.

See `docs/RECONSTRUCTION.md` for the source map, restored route names, receipt verification, deletion boundaries, and remaining Microsoft identity integration. The demo is synthetic and loopback-only.

See `docs/RECOVERY_MANIFEST.md` before changing architecture.

The current `recovered-build/` directory contains immutable reference artifacts from the published Floot build. Do not edit those files directly.
